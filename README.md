# Webパーツ逆引きノート v1

作りたい動きから、HTML・CSS・JavaScriptの組み込み方を探す学習用アプリです。仕様1.1では、基礎2種類に加えて応用の「立体回転ギャラリー」を収録しています。完成ファイルは `web-parts-reverse-v1.html` だけです。インストール、ログイン、サーバー、ビルド、外部の画像やフォントは不要です。

## 開き方

1. `web-parts-reverse-v1.html` を自分のパソコンへ保存する。
2. そのファイルを Chrome などのブラウザーで開く。インターネットを切っていても、見本・調整・コードのコピーと保存が使えます。
3. 最初の画面で、次の3つから選ぶ。
   - スクロールすると順番に現れる
   - クリックすると画像を拡大
   - 円形に回る画像を、手前に拡大【応用】

Dreamweaver へ移すときは、アプリ内の「自分のページに組み込む」に出した断片を使います。アプリ本体を制作中のページへ丸ごと貼る必要はありません。

## 初版でできること

- 3種類の見本を、自分の文章と JPEG・PNG・WebP で調整する。1枚の上限は4MB。スクロール表示と画像拡大は最大6枚・合計12MB、回転ギャラリーは最大12枚・合計20MB。
- 同じ設定から、画面の見本、確認用HTML、既存ページ用のHTML断片・CSS・JavaScriptを作る。
- 確認用HTML（`reveal-example.html` / `lightbox-example.html` / `orbit-example.html`）は、アプリを閉じたあと単独で開ける。利用者の画像もファイル内に埋め込まれる。
- 既存ページ用は、画像を `images/wpr-reveal-…`、`images/wpr-lightbox-…`、`images/wpr-orbit-…` の相対パスで示す。対応表の名前で images フォルダーへ置く。
- コードのコピーに失敗した場合は、コード欄を選択して手動でコピーできる。
- スクロール表示は、JavaScriptが動かないときは本文が見えたままになる。回転ギャラリーも、JavaScriptが動かないときは重ならない普通の一覧になる。
- 動きを減らす設定では、出現・拡大のアニメーションを省き、回転ギャラリーは止めたまま前後送りと拡大が使える。「回転を再開」でも端末の設定は上書きしない。
- 3種類を同じページへ置いても、同種を2組置いても、互いに上書きしない。

### 立体回転ギャラリー

横長の楕円に沿って画像が回る。奥は小さく暗く、手前は大きく明るい。画像を選ぶと、その位置から中央へ移動して拡大し、閉じると元の位置へ戻る。奥の画像も、正面へ回すのを待たずに、押した位置から拡大する。

通常の調整は、自動回転、1周の時間（12〜60秒）、奥の明るさ、拡大の時間。方向・楕円の厚み・奥の大きさは「詳しく調整」に入っている。1〜2枚のときは回転せず、その場で拡大できる。

## 保持される範囲

調整、文章、取り込んだ画像は、このアプリのページを開いている間だけ残ります。再読み込みすると初期の見本に戻ります。残したい場合は「確認用HTMLを保存」してください。アプリは画像を外部へ送りません。

- Safari: 未実施
- スマートフォン実機: 未実施（画面幅の確認のみ）

## 残っている制限

- 初版のパーツは上記3種類だけ。アコーディオン、タブ切り替え、一般的な横スライド、ドラッグによる回転、ピンチ、拡大中の前後移動、jQuery版はない。
- 回転ギャラリーは、クラスを1つ足すだけでは既存の一覧に付かない。専用のステージへ画像を移す。
- ページを開き直したあとの設定と画像の復元はない。
- 画像の自動圧縮と、画像一式のZIP書き出しはない。
- SVG・GIF・動画の取り込みと、外部画像URLの入力はない。
- Safari とスマートフォン実機では未確認。

## 開発ソースを再生成する場合

利用者は再生成しなくてよい。分割しているソースは `wpr-src/`（`app.js`、`app.css`、`reveal.js`、`reveal.css`、`lightbox.js`、`lightbox.css`、`orbit.js`、`orbit.css`）で、次で両方のHTMLを作り直す。

```
node scripts/build-wpr.mjs
```

出力先は `web-parts-reverse-v1.html` と、プレビュー用の `public/web-parts-reverse-v1.html`。
